# Tableau-Project
This project is an interactive data analysis dashboard built using Tableau to explore and evaluate customer satisfaction for British Airways based on passenger reviews.  The analysis focuses on identifying patterns in airline service quality across multiple dimensions and transforming raw review data into actionable insights for decision-making.
