# Tableau-end-to-end-Portofolio-Project

### Project Overview
This project is an interactive data analysis dashboard built using Tableau to explore and evaluate customer satisfaction for British Airways based on passenger reviews.  The analysis focuses on identifying patterns in airline service quality across multiple dimensions and transforming raw review data into actionable insights for decision-making.

🔗 View dashboard: Click here---> (https://public.tableau.com/app/profile/ruth.simon/viz/BRITISHAIRWAYSSERVICEDASHBOARD/Dashboard1)

### Data sources

British Airways Reviews: The primary dataset is the file "ba_reviews.csv" containing different reviews across different dimensions, including Cabin Staff Service
Food & Beverages, Entertainment ratings.

### Tools

Excel — Data cleaning, preparation, and initial exploration
Tableau — Interactive dashboards, visual analytics, and reporting
